Тест по заданию №1. Количественные параметры информационных объектов

Проверьте свои знания по теме кодирования информации и работы с числовыми параметрами

Задание 1: Определение информационного объема

В кодировке Unicode каждый символ кодируется 16 битами. Определите размер следующего предложения в данной кодировке:

«Я изучаю информатику!»

Задание 2: Кодирование чисел

Для кодирования некоторой последовательности, состоящей из букв А, Б, В, Г, Д, решили использовать неравномерный двоичный код, удовлетворяющий условию Фано. Для букв А, Б, В использовали соответственно кодовые слова 00, 01, 100. Какое наименьшее возможное количество символов может быть в коде для буквы Г, если код Д будет на 1 символ длиннее?

Задание 3: Работа с таблицей кодов

Дана кодовая таблица:

Символ Код
А00
Б01
В100
Г101
Д110

Закодируйте слово «БАГАЖ» и укажите его длину в битах.

Задание 4: Перевод единиц измерения

Сколько мегабайт информации содержит сообщение объемом 223 бит?

Правильный ответ: 1 МБ (2²³ бит = 1 МБ)

Задание 5: Определение количества символов

Сообщение, записанное буквами из 128-символьного алфавита, содержит 30 символов. Какой объем информации оно несет в байтах?
